# 결선 시연용 노면 사진 인쇄본

`IcePredict_시연용_노면사진_인쇄.pdf` — A4 10쪽, 쪽마다 17 cm 정사각형 사진 하나 (모델은 카메라 화면 가운데 정사각형만 본다).
1~6쪽 블랙아이스, 7~8쪽 마른 노면, 9~10쪽 젖은 노면. 무광 종이에 컬러, '실제 크기'로 인쇄한다.

블랙아이스 사진은 RSCD 빙판 3,170장 중 무작위 500장을 가혹한 변형으로 거른 뒤 상위 40장을 화면 재촬영 변형 6종
(3배 확대 흐림, 흐림+JPEG, 반사·대비 저하, 화면 줄무늬, 푸른 색온도)으로 다시 판정해, **최소 빙판 확률이 0.97 안팎**인 것 중
눈처럼 보이지 않는 6장을 골랐다. 인쇄 쪽을 다시 잘라 흐림을 줘도 블랙아이스 0.97, 마른 노면 0.97, 젖은 노면 0.94~0.96.

시연: RealSense 에서 30~40 cm, 사진이 판정 네모(+/− 키)를 꽉 채우게. 뒤에 창문만 없으면 배경은 상관없다(카메라 자동 노출만 영향).
