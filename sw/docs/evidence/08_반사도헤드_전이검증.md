# 반사도 헤드는 실사진으로 전이됐는가

융합식 `risk = (α·p_ice + β·spec)/(α+β)` 에서 β(0.45)가 가장 큰 가중치인데, 그 `spec` 을 내는 헤드는 **CARLA 합성 라벨로만 학습**됐다 (실사진 RSCD 에는 반사도 정답이 없어 손실에서 제외했다). 실사진 **69,358장**의 보드 출력으로 그 신호가 실제로 쓸모 있는지 확인한다.

## 1. 클래스별 반사도 분포

| 클래스 | 장수 | 평균 | p05 | 중앙값 | p95 |
|---|---|---|---|---|---|
| normal | 19,018 | 0.140 | 0.000 | 0.000 | 0.891 |
| wet | 34,440 | 0.650 | 0.044 | 0.707 | 1.000 |
| black_ice | 6,340 | 0.978 | 0.891 | 1.000 | 1.000 |
| pothole | 9,560 | 0.844 | 0.186 | 1.000 | 1.000 |

## 2. 반사도 **단독** 판별력 (AUC)

분류 확률을 전혀 쓰지 않고 반사도만으로 얼음과 각 클래스를 가를 때의 AUC 다. 0.5 면 무작위, 1.0 이면 완전 분리다.

| 대조 | AUC | 해석 |
|---|---|---|
| 얼음 vs normal | **0.973** | 강함 |
| 얼음 vs wet | **0.896** | 강함 |
| 얼음 vs pothole | **0.661** | 약함 |
| 얼음 vs 나머지 전체 | **0.883** | |
| (참고) 분류 확률 p_ice 단독 | 0.998 | |

## 3. 반사도는 분류기와 **다른 정보**를 주는가

반사도와 얼음 확률의 상관계수는 **0.356** 다. 겹침이 크지 않다 — 서로 보완하는 신호다.

분류기가 얼음을 놓친 사진(292장) 중 **50.3 %** 는 반사도가 0.8 이상이다 — 그만큼은 반사도 항이 건져 낸다.
반대로 분류기가 얼음이 아닌 것을 얼음이라 한 사진(281장) 중 **89.3 %** 도 반사도가 높아 오경보를 함께 밀어 올린다.

## 4. OpenCV 고전 추정치와 얼마나 맞나

같은 사진 1,500장에 대해 학습 헤드의 반사도와 `icepredict.pi.reflectance` 의 OpenCV 점수(고휘도 비율 + 히스토그램 첨도)를 비교했다.

| 항목 | 값 |
|---|---|
| 두 추정치의 상관계수 | **-0.139** |
| 학습 헤드 — 얼음 vs 나머지 AUC | 0.880 |
| 고전 추정치 — 얼음 vs 나머지 AUC | 0.395 |

두 추정치가 **별로 안 맞는다.** 학습 헤드가 고전적 정반사 점수를 재현하는 것이 아니라 다른 무언가를 배웠다는 뜻이다. AUC 를 비교해 어느 쪽이 실제로 얼음을 가르는지 보면 된다.

## 5. 그래서 β 는 얼마여야 하나 — 판별력 직접 측정

문턱을 어디에 두든 상관없이, 융합값이 얼음을 얼마나 잘 가르는가(AUC)는 β 만으로 정해진다. 실사진에서 직접 쓸어봤다 (α=0.35 고정, 차선 항 없음).

| β | 얼음 판별 AUC | 오경보 5 % 이하 조건에서 얼음 경보율 |
|---|---|---|
| 0.00 | **0.9975** | 97.7% (문턱 0.20, 최악 오경보 1.7%) |
| 0.05 | **0.9942** | 98.3% (문턱 0.20, 최악 오경보 2.9%) |
| 0.10 | **0.9924** | 98.4% (문턱 0.25, 최악 오경보 4.6%) |
| 0.15 | **0.9911** | 98.2% (문턱 0.33, 최악 오경보 4.1%) |
| 0.20 | **0.9899** | 97.9% (문턱 0.39, 최악 오경보 4.0%) |
| 0.30 | **0.9883** | 97.6% (문턱 0.48, 최악 오경보 4.8%) |
| 0.45 **(현행)** | **0.9865** | 97.1% (문턱 0.58, 최악 오경보 3.9%) |
| 0.60 | **0.9852** | 96.9% (문턱 0.64, 최악 오경보 4.7%) |

**AUC 가 β 에 대해 단조 감소한다.** 즉 실사진에서는 반사도를 섞을수록 얼음 판별이 **나빠진다.** β=0(분류 확률만)이 0.9975 로 최고이고, 현행 β=0.45 는 0.9865 다.

이유는 §2·§3 에 있다 — 반사도는 얼음과 `normal` 은 잘 가르지만(AUC 0.970) `pothole` 과는 거의 못 가른다(0.658). 그런데 분류기는 그 셋을 모두 잘 가른다. 그래서 반사도를 섞으면 포트홀이 얼음 쪽으로 끌려 올라온다.

> **주의 — 도메인이 갈린다.** 이 결론은 실사진에 한한다. CARLA 데모에서는 분류기가 폭우·야간에 얼음을 거의 못 보기 때문에(얼음 확률 0.02 수준) 반사도 항이 없으면 1차 경보가 아예 안 난다. 즉 **데모가 β 에 기대고 있는 것은 분류기가 그 도메인에서 약하기 때문**이지 반사도가 좋아서가 아니다.

## 결론

- 반사도 헤드는 CARLA 합성 라벨로만 학습됐는데도 실사진에서 얼음 vs 나머지 **AUC 0.883** 을 낸다. 전이 자체는 성공이다.
- 다만 §5 에서 보듯 **β 를 올릴수록 얼음 판별 AUC 가 단조 감소한다** (β=0 에서 0.9975 → β=0.45 에서 0.9865). 실사진에서는 반사도가 도움이 아니라 방해다. 포트홀을 못 가르기 때문이다.
- 그런데 CARLA 데모는 그 반대다 — 분류기가 약한 도메인이라 반사도가 없으면 1차가 아예 발화하지 않는다. **제품 운영점과 데모 운영점을 분리해야 하는 이유가 하나 더 늘었다.**
- **문서의 "RoadSaW 반사도 헤드 미착수" 항목은 이제 이렇게 바뀐다**: 합성 라벨로도 쓸 만한 신호가 나왔으니 RoadSaW 확보는 급하지 않다. 대신 **β 를 낮추거나 문턱을 올리는 쪽**이 먼저다.
