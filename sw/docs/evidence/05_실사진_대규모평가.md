# 실사진 대규모 보드 평가 (인-더-루프)

RSCD 실사진 **69,358장**을 STM32N6 보드에 직접 넣어 받은 판정이다. 시뮬 화면이 아니라 실제 도로 사진이고, 추론·융합 모두 보드에서 돈다.

표본별 원본은 `logs/rscd_board_samples.jsonl` 에 있다 — 문턱을 바꿔 다시 계산할 때 보드를 다시 돌릴 필요가 없다.

> 처음에는 클래스별 균등 표집(각 6,500장 안팎)이었고, 뒤에 **전량**으로 늘렸다. 그래서 클래스별 장수가 고르지 않다. 아래 수치는 전부 **클래스별 비율**이라 표본 구성이 바뀌어도 그대로 비교할 수 있다. 다만 전체를 한 덩어리로 묶은 "평균 정확도" 같은 값은 구성에 휘둘리므로 쓰지 않는다.

## 1. 클래스별 성능

| 실제 클래스 | 장수 | 정답률 | 경보율(운영 문턱 0.603) | 평균 위험도 | 평균 반사도 |
|---|---|---|---|---|---|
| normal | 19,018 | 0.807 | 0.003 | 0.059 | 0.140 |
| wet | 34,440 | 0.846 | 0.008 | 0.201 | 0.650 |
| black_ice | 6,340 | 0.961 | 0.966 | 0.944 | 0.978 |
| pothole | 9,560 | 0.902 | 0.003 | 0.388 | 0.844 |

> **경보율은 보드의 alarm 플래그가 아니라 `risk >= 문턱` 으로 계산했다.** 보드 융합기에는 히스테리시스가 있어(켜질 땐 0.441, 꺼질 땐 0.341) 연속 영상에서는 깜빡임을 막아 주지만, 서로 무관한 **낱장 사진**을 이어 넣으면 앞 사진의 상태가 넘어온다. 실제로 이번 표본에서 `alarm=True` 인데 `risk < 0.441` 인 경우가 1388건 (2.0 %) 있었다. 기존 `rscd_in_the_loop.py` 결과는 그만큼 경보율이 부풀려져 있다.

## 2. 혼동 행렬 (행 = 실제, 열 = 예측)

| 실제 \ 예측 | normal | wet | black_ice | pothole |
|---|---|---|---|---|
| **normal** | 80.7% | 4.9% | 0.3% | 14.1% |
| **wet** | 5.5% | 84.6% | 0.8% | 9.2% |
| **black_ice** | 1.4% | 1.9% | 96.1% | 0.6% |
| **pothole** | 3.3% | 6.4% | 0.1% | 90.2% |

## 3. 문턱 곡선 — 실사진 기준

이 표가 운영점 결정의 근거다. 얼음은 높게, 나머지는 낮게 나와야 한다.

| 문턱 | normal 경보율 | wet 경보율 | black_ice 경보율 | pothole 경보율 |
|---|---|---|---|---|
| 0.441 (교정 전) | 2.5% | 8.5% | 98.1% | 51.3% |
| 0.500 | 2.2% | 6.0% | 97.7% | 46.5% |
| 0.550 | 1.9% | 4.3% | 97.2% | 42.3% |
| 0.570 | 0.5% | 1.8% | 97.0% | 4.6% |
| 0.603 **(운영)** | 0.3% | 0.8% | 96.6% | 0.3% |
| 0.650 | 0.2% | 0.6% | 96.0% | 0.2% |
| 0.700 | 0.2% | 0.5% | 95.4% | 0.1% |
| 0.750 | 0.2% | 0.4% | 94.7% | 0.1% |

**얼음 외 오경보 5 % 이하를 만족하는 가장 낮은 문턱: 0.570** — 그때 얼음 경보율 97.0 %, 최악 오경보 4.6 %

## 4. 보드 추론 시간

| 지표 | 값 |
|---|---|
| 평균 | 25.49 ms |
| 중앙값 | 25.49 ms |
| p99 | 25.52 ms |
| 최대 | 25.55 ms |
| 최소 | 25.41 ms |
| 표본 | 69,358회 |

편차가 0.14 ms 로 평균의 0.5 % 다. NPU 추론은 입력 내용과 무관하게 **고정 비용**이라는 뜻이고, 그래서 상위 제어의 주기를 설계할 수 있다.
