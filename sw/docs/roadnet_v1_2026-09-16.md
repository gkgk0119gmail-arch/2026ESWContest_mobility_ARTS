# RoadNet v1 학습 결과 (2026-09-16)

MobileNetV3-Small(ImageNet 사전학습) + 4클래스 헤드. RSCD 95.9만 장 학습, 클래스 균형 샘플링
(에폭당 20만 장 × 8에폭), AdamW + 코사인 스케줄, AMP, 224×224.
소요 시간 약 25분 (RTX 3090). 산출물: `models/roadnet_v1/{best.pt, roadnet.onnx}`

## 해석
- **블랙아이스 재현율 0.993.** 4,700장 중 놓친 것 31장. 안전 관점의 핵심 지표를 확보했다.
- **블랙아이스 오검출도 낮다.** normal/wet을 black_ice로 잘못 본 경우 126장(0.3%).
  불필요한 경고로 운전자 신뢰를 잃는 위험이 낮다.
- pothole 정밀도 0.699는 normal/wet의 severe 요철을 pothole로 부르는 매핑 정의 때문.
  블랙아이스 판정에는 영향 없어 현 단계에서는 허용.
- OpenCV 반사도 휴리스틱(AUC 0.64~0.82)보다 CNN이 압도적. 융합 가중치는 α(분류)를 높게 유지.
