# 진행 상황 인수인계 (2026-09-16)

## 환경
| 장비 | 상태 |
|---|---|
| Raspberry Pi 5 (16GB) | SSD 1TB → `/mnt/ssd`, 프로젝트 `~/icepredict` (바탕화면 바로가기 있음) |
| AI HAT+ 2 (Hailo-10H) | PCIe Gen3 인식, hailo-h10-all 5.1.1, yolov11m 71fps 확인 |
| 데스크탑 user@desk-host | RTX 3090, Ubuntu 22.04, SSH 키 등록됨. CARLA 0.9.16 + STM32CubeIDE |
| 네트워크 | 학교망이 유선↔무선 차단. Pi(WiFi)→데스크탑(유선) 단방향만 가능. Tailscale은 학교 도메인 조직 한도로 불가 |
| 기상청 API | `secrets.yaml`에 키 저장, 실황 수신 확인 |

## 완료
1. **Pi 측 코드** — 프로토콜, 기상 컨텍스트, 베이지안 융합, IMU 칼만 미끄러짐 감지, OpenCV 반사도. 테스트 18개 통과
2. **RoadNet v1** — RSCD 95.9만 장 학습. 테스트 정확도 0.910, **black_ice 재현율 0.993**. `models/roadnet_v1/`
3. **CARLA 데모** — 자율주행 + 이중 방어 동작 확인. 영상 `logs/carla_demo/`
   - 1차: 50m 앞 경고 → 빙판 33.7m 전 정지 (단 `--gt-detect`, 카메라 아님)
   - 2차: 진입 후 0.72초에 미끄러짐 감지 → 비상 제어 정지
4. **빙판 시각화** — friction trigger는 렌더링 안 되므로 도로면 폴리곤을 카메라에 투영해 표시

## 미해결 (우선순위 순)
1. **도메인 갭** — RSCD 학습 모델이 CARLA 화면에서 black_ice 확률 최대 0.016. 1차 방어가 카메라로는 동작 안 함
   - 해결책: `sw/scripts/sim/carla_collect.py`로 합성 데이터 1만 장 생성 → RoadNet 미세조정
   - `sw/src/icepredict/sim/ice_render.py`가 물리 기반 얼음 외형 합성 (전반사·어두워짐·질감소실·페더링 경계)
   - 수집기 스모크 테스트 중 액터 파괴 크래시 → 수정 완료, 재검증 필요
2. **INT8 양자화 실패** — ONNX Runtime PTQ로 정확도 0.91→0.48 붕괴. per-channel/보정법/conv-only 모두 무효
   - 원인: features.1 첫 depthwise Conv에서 이미 최대오차 15 (MobileNet 계열 알려진 난제)
   - 다음 시도: QAT, 또는 벤더 툴체인(STM32Cube.AI / Hailo DFC) 자체 양자화기 사용
   - 두 툴체인 모두 계정 로그인 필요한 수동 다운로드
3. **반사도·차선 헤드** — 현재 미학습. CARLA 자동 라벨 확보 후 멀티태스크 확장
4. **하드웨어** — 이더넷 스위치 미구입. STM32N6 보드 펌웨어 미착수. MOZA 핸들 미연결
