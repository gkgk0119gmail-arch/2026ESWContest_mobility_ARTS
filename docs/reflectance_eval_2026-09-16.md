# OpenCV 반사도·차선 알고리즘 RSCD 실사진 검증 (2026-09-16)

- 데이터: RSCD test_50k, 클래스별 400장 무작위 (seed 0), 360×240 노면 패치, ROI 미적용
- 스크립트: `sw/scripts/model/eval_reflectance.py --per-class 400`

## 결과 (spec 점수로 ice 구분 AUC)
| 비교 | AUC |
|---|---|
| ice vs wet-asphalt | 0.82 |
| ice vs water-asphalt | 0.81 |
| ice vs dry-asphalt | 0.64 |
| ice vs fresh_snow | 0.53 |
| ice vs dry-concrete | 0.35 (역전) |

차선 가시성 점수는 모든 비교에서 0.44~0.46 (무작위 수준).

## 해석
- 반사도 휴리스틱은 "얼음 vs 젖음"에는 유효하지만 마른 밝은 노면(콘크리트)과는 구분 못 함.
  국소 하이라이트 방식(v2)도 시도했으나 더 나빠져 v1 유지.
- RSCD는 주간 촬영 노면 패치라, 계획서의 야간 헤드라이트 전반사 가설을 검증하는 데이터가 아님.
  야간 검증은 CARLA 야간 씬 + 실차 야간 촬영이 필요.
- 차선 점수는 노면만 잘라낸 패치에서는 의미 없음. 전방 풀프레임(CARLA·실차)에서만 유효.

## 결정
- 1차 감지의 주 신호는 CNN 분류 헤드. OpenCV 반사도는 보조 신호로 β 가중치를 낮게 시작(0.3→0.15 검토).
- 계획서의 헤드 2(반사도 회귀)·헤드 3(차선 가시성)는 CNN 헤드로 학습하고,
  라벨은 CARLA에서 자동 생성(야간 전반사 강도, 차선 마스크 가시 비율)하는 방향으로 진행.
