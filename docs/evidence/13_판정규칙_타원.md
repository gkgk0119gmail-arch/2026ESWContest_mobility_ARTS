# 2차 방어 판정 규칙 — 직사각형에서 타원으로

## 1. 무엇이 문제였나

변동 스윕(`정리/11`)에서 35 km/h 주행의 빙판 진입 → 미끄러짐 확정이 **5.00 s** 였다. 40 km/h 는 1.78 s, 45 km/h 는 1.10 s.

확정 순간의 잔차를 열어 보니 **ay_g 0.287 · yaw_err 0.353** 이었다. 횡가속도 임계가 0.300 이니 **4 % 차이로** 못 넘은 것이다.
그래서 훨씬 느린 yaw 경로가 0.35 에 닿을 때까지 3.2 s 를 더 기다렸다.

두 잔차를 OR 로 묶은 **직사각형 판정의 모서리에 딱 걸렸다**. 위험은 두 축에 나뉘어 있었는데 판정은 축마다 따로 물었다.

## 2. 어떻게 고쳤나

```
직사각형(기존)  |ay_g| >= 0.30  또는  |yaw_err| >= 0.35
타원(변경)      (ay_g/0.30)^2 + (yaw_err/0.35)^2 >= 1
```

타원은 한쪽만 넘어도 발화하는 성질을 그대로 가진다 — **정의상 기존보다 늦어질 수 없다**.
대신 둘 다 0.71 쯤인 구간을 새로 잡는다. 새 상수도, 속도 보정도 필요 없다.

임계값을 그냥 낮추는 안과 속도로 정규화하는 안도 봤지만 둘 다 버렸다. 낮추면 오경보가 늘고, 속도 정규화는 고속에서 임계가 올라가 **도리어 둔해진다**.

비용은 곱 2 + 합 1, 분기 수는 그대로다. 보드 WCET 에 영향이 없어야 하고, 실제로 재 봤다 (아래 5절).

## 3. 얼마나 빨라지나

미끄러짐 세기를 낮춰가며 두 규칙의 확정 시각을 잰다. 35 km/h 기준, 진입은 2.00 s.

| yaw 증가 (rad/s) | 횡가속 증가 (g) | 직사각형 | 타원 | 차이 |
|---|---|---|---|---|
| 0.90 | 0.45 | 2.32 s (yaw_rate) | 2.30 s (yaw_rate) | **+0.02 s** |
| 0.60 | 0.30 | 2.44 s (yaw_rate) | 2.40 s (yaw_rate) | **+0.04 s** |
| 0.45 | 0.22 | 2.54 s (yaw_rate) | 2.54 s (yaw_rate) | 같음 |
| 0.36 | 0.18 | 2.80 s (yaw_rate) | 2.56 s (combo) | **+0.24 s** |
| 0.30 | 0.15 | 못 잡음 | 3.66 s (combo) | **새로 잡음** |
| 0.24 | 0.12 | 못 잡음 | 못 잡음 | - |
| 0.18 | 0.09 | 못 잡음 | 못 잡음 | - |

- 더 빨라진 조건 3 건, **기존이 아예 못 잡던 것을 새로 잡은 조건 1 건**.
- 느려진 조건은 없다. 있을 수 없다 — 타원은 직사각형을 안에 품는다.
- 약한 미끄러짐(yaw 0.24 이하)은 둘 다 못 잡는다. 거기는 규칙이 아니라 센서·임계의 문제이고, 허용 예산은 `정리/09` 에 있다.

## 4. 대가가 있나 — 정상 주행 오탐

민감하게 만들었으면 오경보를 같이 재야 한다. 미끄러짐이 전혀 없는 주행을 만들어 센다.

| 조건 | 시행 | 직사각형 | 타원 |
|---|---|---|---|
| 직진 · 노이즈 1~3배 | 300 | 0 | 0 |
| 곡선 · 조향 0.12~0.30 | 180 | 0 | 0 |

오탐이 **양쪽 다 0** 이다. 타원이 넓히는 영역은 두 잔차가 **동시에** 임계의 0.71 을 넘는 곳인데, 정상 주행에서는 두 잔차가 그렇게 함께 커지지 않는다.
잔차가 이미 자전거 모델로 조향 성분을 뺀 값이라 그렇다.
